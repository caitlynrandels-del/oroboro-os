# Oroboro OS

Deterministic operating system built from the Oroboro framework.

## Boot Sequence
- Genesis seals the origin identity
- Nexus becomes the single source of truth
- Transcriber + Dictator + Levy come online
- Full GitHub archive (26 repositories) is registered into Nexus

## Usage
Open `oroboro-os.html` in any browser. It runs immediately.

### Commands
- `help` — list commands
- `repos` — list the entire GitHub archive
- `open <repo-name>` — open a repository as a process
- `spawn <name>` — create an independent part
- `reduce` — run relational reduction
- `status` / `history` / `weight`

Created as a living system from the Oroboro components.
